Laravel Snip

This page plays the host app. It feeds the built panel (dist/snip.js) fake data: choose what each tab gets below, then open the snip pill or press Cmd+K. Run npm run dev and reload to see source changes.

SnipsValues captured with \Snip::add()
Timings\Snip::start() / \Snip::timing()
Milestones\Snip::milestone()
MailSNIP_MAIL / SNIP_MAIL_CATCH; off shows the setup steps
ProfilerOff hides the tab
InertiaA fake Inertia page; off hides the tab
Theme, corner, size and open state are kept in localStorage.

Every tab is empty and the profiler and Inertia are off, so the panel hides its pill, as it does in an app.
